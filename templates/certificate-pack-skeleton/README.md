# Certificate pack skeleton (SAMPLE_LAB DUMMY)

Shared templates for `scripts/catalogue/generate-certificate-packs.mjs`.

Policy slots render **SAMPLE_LAB DUMMY** synthetic defaults (tenant-overridable), not
`POLICY_INPUT_REQUIRED` sentinels. Residence (`IND-SOC-002`) is hand-crafted and skipped.
Income (`IND-SOC-031`) is hand-crafted but uses the same dummy defaults.

See `templates/certificate-packs/sample-lab-dummy/`.
