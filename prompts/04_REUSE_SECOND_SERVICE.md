# Cursor Task - Second-Service Reuse Proof

After Residence Certificate passes the approved gates, onboard a second service (default: Income Certificate) primarily through ServiceForm Studio configuration.

Do not create service-specific backend code unless an approved ADR identifies a reusable capability gap. Produce a delta report showing which artifacts changed: form, rules, evidence, workflow, access, SLA, credential, notifications. If code changes are needed, first propose the smallest generic platform capability that would also serve other services.
