# Domain Glossary

- **Canonical Service**: normalized national concept used for discovery/analytics/interoperability; does not erase local legal distinctions.
- **Local Service Offering**: a tenant/jurisdiction/provider-specific, versioned implementation of a canonical service.
- **Tenant**: security and governance boundary for one or more government organizations.
- **Organization**: legal/administrative government body.
- **Office**: operational unit that performs service work.
- **Jurisdiction**: geographic/administrative area represented as typed hierarchical data.
- **Provider Binding**: rule resolving the competent office/authority for an applicant/service.
- **Application/Case**: citizen request pinned to exact published dependency versions.
- **Claim**: provenance-aware citizen/profile fact with source, verification, freshness and purpose metadata.
- **Evidence**: document/data assertion used to satisfy a service requirement.
- **Rule Set**: deterministic eligibility/fee/evidence/SLA/routing logic.
- **Workflow Definition**: versioned process graph; runtime instances pin its version.
- **Credential**: issued structured outcome with signed document/status/verification representation.
- **Projection**: non-authoritative derived representation such as search index, analytics view or vector embedding.
